# AI Website Analytics Assistant

Upload website traffic data (CSV) and ask questions in plain English. The app calculates
the statistics in Python, then uses Claude to explain the results and suggest improvements.

## How it works
1. `analytics.py` reads the CSV and calculates totals, bounce rates and growth per page.
2. `ai_helper.py` sends those numbers (not raw data) to Claude with the user's question.
3. `main.py` is the FastAPI server connecting the two. `static/index.html` is the UI.

## Run it
```
pip install -r requirements.txt
export ANTHROPIC_API_KEY=your_key   # optional; without it a simple summary is shown
uvicorn main:app --reload
```
Open http://127.0.0.1:8000

## Design decisions
- Code does the maths, AI only explains. This avoids made-up numbers.
- API key comes from an environment variable and is never committed.
- If the AI call fails, the app falls back to a rule-based summary.

## Ideas for improvement
